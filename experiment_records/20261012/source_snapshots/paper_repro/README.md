# Archived paper_repro source

We retain this source snapshot to identify the implementation associated with the indexed development records. The retained training, model, data-loader, and configuration-generator files preserve their original content; [checksums](../../source_snapshot_checksums.json) identify them.

For current execution, use the [revision implementation](../../../../revision/README.md). The archive and current implementation have different input pathways, DM parameterization, and encoder adaptations, so their configurations and result records should be interpreted with their respective source versions.

This archive documents the original operator and training definitions. It is not a substitute for the corrected dispersion operator in `revision/`, and its source identity is retained rather than retroactively changed. Temporary desktop-process and hardware-diagnostic utilities are excluded from the research source release.
